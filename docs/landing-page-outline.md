## HOW FAIRGROUND IS DIFFERENT

**Section Title:**  
Built on Fairness — By Design

**Three Core Principles (Bulleted):**

*   **One Request. One Contractor.**  
    No auctions. No shared requests. No bidding wars.

*   **Contractor Control.**  
    Service providers decide how many requests they receive and can pause requests at any time.

*   **Collaboration Over Competition.**  
    If a job requires additional skills, contractors are encouraged to partner with other providers—not compete against them.

***

## HOW IT WORKS (SIMPLE FLOW)

**Section Title:**  
How FairGround Works

**Step‑by‑Step:**

1.  **Service Providers Join the Network**  
    Create a professional profile and receive a unique FairGround request link.

2.  **Clients Submit One Exclusive Request**  
    Clients can submit a request via a provider’s link or by browsing the network—but they may only submit one active request at a time.

3.  **No Bidding, No Shopping**  
    Requests are exclusive. Contractors are not competing against others for the same job.

4.  **Get the Job Done — or Close the Request**  
    Contractors either complete the job (by any lawful means, including collaboration) or formally close the request.
